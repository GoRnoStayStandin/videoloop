# VideoLoop

Лёгкая программа для зацикленного воспроизведения локальных видео и контроля VLC.

## Требования

- **Windows 7 SP1 или Windows 10**, 32 или 64 бита.
- **.NET Framework 4.8** — установщик `VideoLoop-Setup.exe` установит его при необходимости. Для переносимой ZIP-версии Framework нужен заранее.
- Установленный **[VLC 3.x](https://www.videolan.org/vlc/)** подходящей для Windows разрядности.
- Видеофайлы на локальном диске.
- Права администратора для установки. Для обычной работы они не нужны.

## Что контролируется

- **Пауза** — воспроизведение возобновляется.
- **Остановка воспроизведения** — видео запускается снова.
- **Вылет или закрытие VLC** — плеер перезапускается с очередью, начиная с первого ролика.
- **Отсутствие ответа или продвижения воспроизведения** — выполняется повторная проверка, затем перезапуск при подтверждении проблемы.
- **Порядок и повтор** — восстанавливаются последовательное воспроизведение и повтор всей очереди.

Интервал проверки — **1, 5 или 10 минут**. Вылет VLC также определяется по завершению процесса, без ожидания очередной проверки.

Кнопка **СТОП** отключает контроль и закрывает только запущенный программой экземпляр VLC. При частых повторных сбоях контроль останавливается с сообщением об ошибке.
