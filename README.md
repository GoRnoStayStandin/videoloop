# VideoLoop

Лёгкая программа для показа локальных видео по кругу и контроля VLC. Интерфейс на русском. Автозапуска показа при включении компьютера нет.

## Требования

- Windows 7 **SP1**, 32 или 64 бита, либо Windows 10, 32 или 64 бита.
- **.NET Framework 4.8**. На Windows 7 и старых выпусках Windows 10 его может потребоваться установить отдельно. Нужен Runtime, не Developer Pack. Официальная загрузка: https://dotnet.microsoft.com/download/dotnet-framework/net48
- Установленный **VLC 3.x** любой разрядности: https://www.videolan.org/vlc/ . На Windows 7 32 bit устанавливайте 32-битный VLC. Программа проверяет версию через интерфейс VLC; другие основные версии пока не поддерживаются.
- Видео на доступном локальном диске.

Один и тот же x86-файл программы подходит для обоих компьютеров. Права администратора для работы не нужны. Доступ к Интернету во время показа не требуется.

## Быстрый запуск

1. Распакуйте `VideoDisplayChecker-win-x86.zip` в обычную папку.
2. Запустите `VideoDisplayChecker.exe`. Файл `VideoDisplayChecker.exe.config` должен лежать рядом.
3. Если VLC не найден автоматически, нажмите **Обзор…** и выберите `vlc.exe`.
4. Нажмите **Добавить видео…**. Можно выбрать несколько файлов. Они воспроизводятся в порядке списка. Одинаковый путь повторно не добавляется; одинаковые названия из разных папок допустимы. Полный путь виден при наведении на название.
5. Выберите интервал проверки: 1, 5 или 10 минут. Рекомендуется 1 минута.
6. Нажмите **СТАРТ**. VLC откроется во весь экран и будет повторять всю очередь.
7. Чтобы остановить показ, переключитесь через **Alt+Tab** к программе и нажмите **СТОП**. В VLC клавиша **F** позволяет выйти из полноэкранного режима и затем свернуть окно.

Программа не поднимает исправный плеер поверх других окон при проверках. Сворачивание не считается сбоем, пауза при сворачивании отключена для управляемого запуска. При перезапуске после вылета новый VLC снова открывается во весь экран.

Во время показа очередь и настройки заблокированы. После СТОП можно удалить отдельный ролик, очистить всю очередь или добавить новые файлы. Удаление из очереди **не удаляет файлы с диска**. Порядок выбора в диалоге Windows может отличаться от порядка щелчков; перед запуском ориентируйтесь на список в программе.

Очередь, путь к VLC и интервал сохраняются. При повторном открытии показ начинается только после СТАРТ. Закрытие программы выполняет СТОП. Одновременно разрешён один экземпляр программы в пользовательском сеансе.

## Что контролируется

- Пауза: отправляется команда продолжения, не переключатель паузы.
- Остановка: воспроизведение запускается снова.
- Вылет или ручное закрытие VLC во время активного контроля: запускается новый экземпляр с очередью, с первого ролика. Сначала выполняется небольшая задержка восстановления.
- Отсутствие ответа: повторная проверка, затем перезапуск при подтверждении.
- Отсутствие продвижения: сравниваются близкие по времени отсчёты позиции, номер элемента и доступные счётчики VLC. При подозрении выполняется дополнительная проверка. Переход к следующему ролику и зацикливание учитываются.
- Отключённый повтор очереди, включённый повтор одного ролика или случайный порядок исправляются при проверке.

Обычная проверка — несколько небольших локальных запросов, между которыми поток спит. После завершения проверки программа ждёт выбранный интервал. Вылет определяется также по событию завершения процесса, поэтому ждать весь интервал не требуется. Запуск VLC на слабом компьютере может занимать до 45 секунд до признания попытки неудачной.

СТОП сначала отменяет проверки и восстановления, затем закрывает **только экземпляр VLC, запущенный этой программой**. Если он не закрывается, через 4 секунды завершается принудительно. Открытые отдельно экземпляры VLC не затрагиваются. Окно программы остаётся отзывчивым во время остановки.

При повторных сбоях задержка растёт от 5 до 60 секунд. После пяти восстановлений в пределах 10 минут следующая ошибка останавливает контроль и выводит причину. Это защищает слабый компьютер от непрерывных перезапусков повреждённого ролика. Исправьте причину и нажмите СТАРТ.

Во время показа программа временно просит Windows не выключать экран и не переходить в автоматический сон. После остановки запрос снимается; настройки питания Windows не меняются. Ручной сон, закрытие крышки и выключение компьютера этим не отменяются.

## Ограничения

- Основная нагрузка — декодирование видео в VLC. Программа не анализирует изображение и не делает скриншоты.
- Если картинка зависла, но таймер и счётчики VLC продолжают меняться, такой сбой может остаться незамеченным.
- Программа не исправляет повреждённые файлы, драйверы и неподдерживаемые кодеки. При устойчивом сбое проверьте тот же файл непосредственно в VLC.
- Принудительное завершение самого приложения через диспетчер задач или отключение питания прерывает контроль; штатное закрытие окна выполняет остановку VLC.
- Совместимость с Windows 7 SP1 заложена в платформу и разрядность сборки; окончательную проверку нужно выполнить на самом ноутбуке.

## Настройки и журнал

Папка: `%LOCALAPPDATA%\VideoDisplayChecker` (вставьте этот путь в адресную строку проводника).

- `settings.xml` — очередь и настройки, `settings.xml.bak` — предыдущая сохранённая версия.
- `events.log` и `events.log.1` — события восстановления и ошибки, примерно по 256 КБ.
- Временный `playlist-....m3u8` создаётся на время работы VLC и удаляется при штатной остановке.

Локальный интерфейс VLC включается параметрами запуска на `127.0.0.1`, со свободным портом и случайным паролем на каждый запуск. Ручная настройка HTTP-интерфейса VLC не нужна. Пароль не записывается в журнал.

## Сборка из исходников

На Windows с .NET Framework 4.8/4.8.1 и Windows PowerShell 5.1:

```
build.cmd
build.cmd -Test
build.cmd -Integration -VlcPath "C:\Program Files\VideoLAN\VLC\vlc.exe"
```

Сборка использует встроенный компилятор .NET Framework, C# 5 и reference assemblies именно .NET Framework 4.8. Если Developer Pack 4.8 отсутствует, при первой сборке скачивается официальный пакет Microsoft reference assemblies версии 1.0.3 с NuGet в `packages`. Повторная сборка работает без загрузки. В готовое приложение этот пакет не входит. .NET SDK не нужен.

Результат: `artifacts\VideoDisplayChecker\VideoDisplayChecker.exe` и `artifacts\VideoDisplayChecker-win-x86.zip`.

Для проверки с настоящим VLC нужен также `ffmpeg` в PATH. Интеграционная проверка создаёт короткие тестовые видео во временной папке, открывает VLC, проверяет очередь, паузу, остановку, перезапуск и закрытие. Во время неё на экране появляются окна VLC. Пользовательские видео и настройки приложения не редактируются.

Проект `src\VideoDisplayChecker.csproj` можно открыть в Visual Studio с компонентами разработки .NET Framework 4.8.

- Готовый EXE запущен отдельно. Размер — примерно **40 КиБ**. На машине разработки в покое после открытия окна: рабочий набор примерно **34 МиБ**, частная память примерно **16 МиБ**; за 10 секунд измерения заметного процессорного времени не накопилось. Эти значения относятся к самому приложению без VLC; на других компьютерах они могут отличаться.
- Проверка на физическом ноутбуке с Windows 7 SP1 остаётся необходимой.

Для повторения замера и сохранения снимка окна после сборки тестов:

```
artifacts\tests\VideoDisplayChecker.Tests.exe --measure
```

Этот диагностический режим открывает и штатно закрывает готовую программу, поэтому используйте его при остановленном показе. Снимок сохраняется в `artifacts\app-preview.png`.
